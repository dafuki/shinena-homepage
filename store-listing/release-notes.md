# Shinena Play Store Release Notes

## English

**1.0-b29**
First-run download: textbook packs (~11 MB) download from GitHub once after
install and work fully offline after that — the APK is now 3.7 MB.
• Hint box fixed: no longer floats over the answer panel, readable on PC
• Design picker moved into Settings (Classic vs Journey); top toolbar removed
• Left walking animation fixed (dedicated left sprite, no more skipping)
• Tapping the stage Shinena stands on opens the stage popup immediately

**1.0-b24**
The complete library now travels with you:
• All 63 Mishna tractates, the full Tanakh, the Babylonian Talmud, Rambam and the Shulchan Arukh are bundled offline
• The adventure map was rebuilt — every chapter is a stage again
• Faster, cleaner chapter and book pickers
• New theme, smoother scrolling and a refreshed look throughout

**1.0-b23**
• Map mascot travel animation and eased map scroll
• Header now has single hamburger menu on mobile, full desktop nav
• Hero fonts enlarged, picker dropdown sizing unified
• Chapter dropdown book-name prefix stripped
• Social leaderboard per-country comparison + global option
• Footer build version `v1.0.0-beta(<commit>)`
